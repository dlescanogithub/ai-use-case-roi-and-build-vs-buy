# Choosing a coding assistant for a side project

Status: **design only**. No scores are committed, because a personal tool choice depends on the person's repos and budget, and this repository does not invent a precise recommendation.

## How the same kit would be used

| Input | Personal meaning |
| --- | --- |
| Build | Editor plus local scripts, no subscription |
| Buy | One fictional assistant product, seat or usage |
| Control | Can the person see and keep the prompts and the project rules |
| Time to value | How soon the assistant is useful on a small repo |
| Exit cost | What is stranded if the account closes: rules files, indexes, chat history |
| Gated effects | Spending money, granting repository access. Both stay a human action |

Weights would likely put more on exit cost and control than Bruma Freight does, and less on a 3-year seat model if the horizon is "this season". That is a hypothesis, not a measured ranking.

## What this page does not do

It does not name a real assistant product, a real price, or a winner.
