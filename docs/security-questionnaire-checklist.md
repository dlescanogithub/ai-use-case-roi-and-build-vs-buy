# Security questionnaire checklist

Status: **checklist only**. Nothing in this repository sends the list, stores answers, or scores a vendor from it. Automation of this list is design-only (see [SCOPE.md](SCOPE.md)).

Use it when a buy option's `security_compliance` rationale mentions a claim. The score records the claim. This list is how a person would ask.

- [ ] Where does the text or audio reside, and in which region?
- [ ] Who are the subprocessors, and where is that list published?
- [ ] Is customer content used to train a shared model? The answer belongs in the score rationale.
- [ ] How long is content retained, and how is it deleted?
- [ ] Is there SSO, and who administers accounts?
- [ ] Are there audit logs the customer can export?
- [ ] What is the export format for transcripts, prompts, and labels?
- [ ] What happens to data at contract end?
- [ ] Is there a published security contact, and where?
- [ ] Which claims are certifications, and which are product descriptions? A score must not upgrade the second into the first.

Date the answers. If an answer cites a public page, keep the URL and the access date next to the TCO envelope, or leave the related price and the score marked as an estimate.
